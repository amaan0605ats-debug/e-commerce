# Deploy Al Gani — Render (free) + TiDB Cloud (free MySQL)

Complete guide: **one free website** on Render + **one free database** on TiDB.  
Repo: https://github.com/amaan0605ats-debug/e-commerce

---

## Part 1 — TiDB Cloud (free database)

1. Go to [https://tidbcloud.com](https://tidbcloud.com) and sign up (free).
2. **Create Cluster** → choose **Serverless** (free tier).
3. Pick a region close to you (e.g. **AWS Mumbai / Singapore** if available).
4. Wait until the cluster status is **Active**.
5. Open the cluster → **Connect** → **General** connection type.
6. Create a database name, e.g. `algani_db` (or use the default).
7. Copy the **connection string**. It looks like:
   ```text
   mysql://xxxxxxxx:xxxxxxxx@gatewayXX.region.prod.aws.tidbcloud.com:4000/algani_db
   ```
8. Keep this string private — you will paste it into Render as `MYSQL_URL`.

**Tip:** If the password has special characters (`@`, `#`, `/`), use TiDB’s “URL-encoded” connection string or encode the password in the URL.

---

## Part 2 — Render (free web service)

1. Go to [https://render.com](https://render.com) → sign in with **GitHub**.
2. **New** → **Blueprint**.
3. Select repository **`amaan0605ats-debug/e-commerce`**.
4. Render reads `render.yaml` → click **Apply** (service name: `algani-website`, plan: **Free**).

### Environment variables

Open the new Web Service → **Environment** → add:

| Key | Value |
|-----|--------|
| `MYSQL_URL` | Paste full TiDB connection string from Part 1 |
| `DB_SSL` | `true` |
| `ADMIN_PASSWORD_1` | Password for admin login (`aftab@algani`) |
| `RESEND_API_KEY` | Resend API key (e.g. `re_...` from resend.com) |
| `RESEND_FROM` | The sender address (e.g. `Al Gani <onboarding@resend.dev>` or your custom domain) |

`JWT_SECRET` is auto-generated by the blueprint.  

If deploy logs show **TLS / certificate** errors, add:

| Key | Value |
|-----|--------|
| `DB_SSL_REJECT_UNAUTHORIZED` | `false` |

5. Click **Save Changes** → **Manual Deploy** → **Deploy latest commit**.

### Build settings (if not using Blueprint)

| Setting | Value |
|---------|--------|
| Build Command | `npm install && npm run build` |
| Start Command | `npm start` |
| Plan | Free |

## Part 3 — Verify

1. Open your site: `https://algani-website.onrender.com` (name may vary).
2. Check API: `https://YOUR-SERVICE.onrender.com/api/health`  
   Should return: `{"ok":true,"database":true}`
3. Submit the **Contact** form → check email inbox.
4. Admin: `https://YOUR-SERVICE.onrender.com/#/admin/login`  
   - Email: `aftab@algani`  
   - Password: value you set for `ADMIN_PASSWORD_1`

| Service | Limit |
|---------|--------|
| **Render** | Sleeps after ~15 min idle; first load can take 30–60 seconds |
| **TiDB Serverless** | Free quota (storage / requests); enough for a small business site |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `database: false` on `/api/health` | Check `MYSQL_URL`, `DB_SSL=true`, cluster is Active |
| TLS error in logs | Set `DB_SSL_REJECT_UNAUTHORIZED=false` |
| Emails not sent | Set `RESEND_API_KEY` and check if your sender domain is verified in Resend |
| 502 on first visit | Wait — free Render instance is waking up |
| Admin login fails | `ADMIN_PASSWORD_1` in Render env; login is `aftab@algani` |

## Alternative — Railway (paid, simpler MySQL)

1. [https://railway.app](https://railway.app) → **New Project** → **Deploy from GitHub** → `e-commerce`.
2. **Add service** → **MySQL** (Railway injects `MYSQLHOST`, `MYSQLPORT`, etc. automatically).
3. Set env on the web service: `ADMIN_PASSWORD_1`, `RESEND_API_KEY`, `RESEND_FROM`.
4. Do **not** set `DB_SSL=true` for Railway’s internal MySQL unless their docs require it.
5. Deploy uses `railway.toml` (`npm run build` + `npm start`). Check `/api/health` → `"database": true`.

Optional: paste Railway’s public `MYSQL_URL` instead of individual vars; set `DB_SSL=true` only for external/public URLs.

---

## Do not use Netlify for this project

Netlify only publishes the `dist/` folder. It does **not** run `server.cjs`, so `/api` and admin will not work. Use Render + TiDB instead.
